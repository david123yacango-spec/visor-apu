# VidBIM · Visor de APU

Página para revisar un presupuesto partida por partida con su análisis de precios unitarios,
explicado línea por línea (cuadrilla × 8 h ÷ rendimiento, % de mano de obra, redondeos).

- Se cargan los Excel de exportación de **Power Cost** o **VidBIM Costos** (Presupuesto y APU).
- Los Excel se leen en el navegador y **no se suben a ningún servidor**.
- Acceso por correo, dado por David desde una hoja de Google.
